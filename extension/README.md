# 演示Demo 录制器 — Chrome 扩展

无需手动截图！操作产品页面，自动截图，一键生成交互式演示走查。

## 安装方法

1. 打开 Chrome，地址栏输入：`chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录（`extension/` 文件夹）
5. 扩展栏出现 **W** 图标即安装成功

## 使用流程

```
① 打开你的产品页面
② 点击扩展图标 → 点击「开始录制」
③ 正常操作产品（每次点击自动截图）
④ 完成后点击「停止录制 & 导入创建器」
⑤ 创建器自动打开，步骤已就位，可添加标注
```

## 功能说明

| 功能 | 说明 |
|------|------|
| 自动截图 | 每次点击页面自动截图，无需手动操作 |
| 手动截图 | 页面工具栏 / 弹出框均有手动截图按钮 |
| 跨页面录制 | 页面跳转后自动继续录制（重新注入脚本） |
| 热点自动标注 | 导入时自动在点击位置添加脉冲热点标注 |
| 配置创建器地址 | 支持本地 localhost 和公网部署地址 |

## 权限说明

- `activeTab` / `tabs`：读取当前标签页 URL 和截图
- `scripting`：向页面注入录制工具栏脚本
- `storage`：保存录制状态和配置
- `webNavigation`：检测页面跳转，自动继续录制
- `<all_urls>`：支持在任意网站录制

## 配置创建器地址

默认地址：`http://localhost:8080/creator.html`

如需修改（例如部署到公网）：
1. 点击扩展图标
2. 底部「创建器地址」输入框中修改
3. 点击「保存地址」
